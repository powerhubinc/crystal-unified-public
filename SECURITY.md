# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via email to: **security@powerhub.inc**

### What to Include

- Type of vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (if available)

### Response Timeline

- **Initial response:** Within 48 hours
- **Status update:** Within 7 days
- **Resolution target:** Varies by severity

### After Reporting

1. We will acknowledge your report within 48 hours
2. We will investigate and determine the impact
3. We will develop and test a fix
4. We will release a patch and credit you (if desired)

### Safe Harbor

We consider security research conducted in good faith to be authorized.
We will not pursue legal action against researchers who:

- Make a good faith effort to avoid privacy violations
- Avoid destruction of data
- Do not exploit issues beyond proof of concept
- Give us reasonable time to respond before disclosure

## Security Best Practices

When using Crystal Unified:

- Keep the library updated to the latest version
- Validate input data before compression
- Handle decompression errors gracefully
- Do not decompress untrusted data without size limits
